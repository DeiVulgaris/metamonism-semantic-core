# D_ext Transition Structure and Partial Operator J

## Research question

Can the continuation set D_ext be equipped with enough structure to represent ordinary continuation and exhaustion-induced regime change as transitions on a common mathematical carrier?

## 1. Do not vectorize D_ext yet

The elements of D_ext are continuation possibilities. They are not assumed to be vectors.

The minimal structure is therefore a directed transition relation:

d ∈ D_ext(S)  iff  S --d--> S'

This gives a family of admissible arrows rather than a vector space.

## 2. Continuation category

Define process states as objects and admissible transitions as morphisms:

Hom_R(S_i,S_j) = { T | T is an admissible continuation under regime R }

Composition is partial:

T_2 ∘ T_1

is defined only when the target of T_1 matches the source of T_2 and the regime constraints are compatible.

The identity here is a process-state identity arrow 1_S. This is categorical identity, not yet the multiplicative identity of an algebra.

## 3. Exhaustion as loss of outgoing continuation arrows

For state S:

Out_R(S) = { T | T ∈ Hom_R(S, -) }

Then:

E_R(S) := Out_R(S) = ∅

is equivalent to exhaustion under the current regime.

This is stronger than merely saying that one selected continuation failed. It says no continuation admissible under that regime remains.

## 4. Frustration boundary

Define:

B_R = { S | Out_R(S)=∅ and NeedContinue(S)=true }

Then:

S ∈ B_R  =>  Fr(S)

The boundary is therefore a subset of process states characterized by the disappearance of admissible outgoing arrows while continuation remains required.

## 5. Regime-changing transition

Introduce:

J_R : B_R → States(R')

where R' is a new continuation regime.

For the Chapter 3 case:

P3 ∈ B_R

and:

J_R(P3)=P4

with the orientation update:

n' = -n

This is a partial transition because its domain is the frustration boundary.

## 6. J is not yet an algebraic operator

J_R is currently a morphism between regime-indexed process structures.

It is not yet:

- a linear map;
- a matrix;
- a reflection;
- a Clifford generator;
- a Lorentz transformation.

In particular, J_R² is not defined until R' and a subsequent domain relation are specified.

## 7. Common carrier candidate

To obtain an operator representation, introduce a formal state-space candidate W whose basis elements correspond to process states or transition classes.

This is deliberately a later construction:

W = Span{ |S_i⟩ }

Only after W is justified may one seek operators:

T_d : W_R → W_R

and:

J_R : W_R → W_R'

The notation does not assert that the physical process is a Hilbert space or vector space.

## 8. Regime-changing operator as a boundary map

If R' is represented on the same W, J can be extended as:

J : W_R → W_R'

But the codomain may differ from the domain.

This distinction is important. A regime transition is naturally a map between structures, not necessarily an endomorphism.

Only if:

W_R = W_R'

and the relevant domains coincide can J become an ordinary endomorphism whose powers can be studied.

## 9. Closure question

The central mathematical test becomes:

Can the new regime be represented on the same carrier without losing the distinction between R and R'?

If yes, then one may investigate:

J²,
J T,
T J,
[J,T],

or an alternative composition structure.

If no, then the process is intrinsically multi-regime and a single fixed algebra may be the wrong mathematical object.

## 10. Relation to P1-P4

The faithful representation is now:

P0 --T0--> P1 --T1--> P2 --T2--> P3

with:

Out_R(P3)=∅

followed by:

P3 --J_R--> P4

rather than:

P0 --g1--> P1 --g2--> P2 --g3--> P3 --g4--> P4.

Thus P4 is generated by a boundary transition, not by another member of the same continuation family.

## 11. Clifford/Dirac research consequence

The earlier candidate set {P1,P2,P3,P4} is no longer the primary algebraic candidate.

A more faithful candidate is:

{T0,T1,T2,T3,J}

but even this is not asserted to be a Clifford generating set.

The research question is:

Does an operator representation of the transition system admit a subalgebra satisfying Clifford relations?

This requires deriving:

- a common carrier;
- a product;
- an identity;
- a bilinear form or equivalent relation;
- anticommutation relations;
- a representation.

None is assumed here.

## 12. New mathematical fork

Two possibilities are now explicit.

### Branch A — common carrier

There exists W such that both ordinary continuation and regime change can be represented on W.

Then:

Transition system → operator algebra → relation analysis → possible Clifford sector.

### Branch B — changing carrier

No common W exists without collapsing the regime distinction.

Then the natural object is a category/groupoid-like or higher transition structure rather than a single fixed algebra.

This branch must remain open.
