# D3 Revision: Exhaustion Before Metric

This revision records a correction to the first D3 formalization.

The source does not motivate `+n -> -n` as a free geometric reflection. It motivates the reversal through exhaustion of further external orthogonal unfolding.

The revised order is:

`continuation structure -> exhaustion -> frustration -> regime transition -> orientation reversal -> state space -> bilinear/algebraic structure`

The earlier D3 remains preserved for comparison and is not deleted or rewritten.
