# Processual Algebra Research Program: D1-D5

## Purpose

This research program tests whether the processual structure described in Chapter 3 can independently generate an algebra that admits a Clifford/Dirac representation.

It does not begin by identifying P1-P4 with Dirac gamma matrices.

The source describes P1-P4 as processual stages/states and permits a future structural comparison with geometric/Clifford algebra and Dirac algebra. It explicitly states that structural isomorphism is not physical identity and that algebraic analogy alone does not derive quantum theory or the Dirac equations.

Therefore the correct order is:

processual structure -> mathematical carrier -> operations -> relations -> algebra -> representation -> comparison

not:

P_i -> gamma_i.

## Source-grounded starting point

Chapter 3 establishes:

- P0 -> P1 -> P2 -> P3 -> P4.
- Successive external unfolding is orthogonal through the first three directions.
- At P3 -> P4 the normal changes orientation: +n -> -n.
- P4 is not presented as a fourth spatial dimension.
- P4 is followed by P5 through frustration-driven continuation into a new localization regime.
- The source permits comparison with Clifford/Dirac algebra but explicitly leaves the mathematical derivation as future work.

These statements are source claims. The algebraic construction below is a working research formalization, not a source claim.

## Critical methodological decision

P1-P4 are treated first as states/processual positions, not as algebraic generators.

If an algebra is to emerge, it must be generated by independently defined objects associated with transitions, directions, orientation operations, or another mathematically justified carrier.

A candidate generator set may eventually be introduced, but only after D1-D3 justify it.

## D1 - Define the carrier

Define a mathematical carrier X on which the processual structure can be represented.

Minimum requirements:

1. X contains representations of the relevant processual states or directional data.
2. The notion of orthogonality is explicitly defined.
3. The orientation change +n -> -n has a mathematically defined meaning.
4. The carrier does not presuppose a Clifford algebra.

Candidate working form:

X = (V, q)

where V is a real or complex vector space and q is a bilinear/quadratic structure.

This is a candidate, not a conclusion. The research task is to determine whether such a carrier follows from the source structure or is merely an externally imposed mathematical representation.

## D2 - Define composition

An algebra requires an operation.

The process P_i -> P_{i+1} is not itself an algebraic multiplication.

Possible candidates include:

- transition composition;
- composition of directional operators;
- composition of orientation transformations;
- composition of processual generators.

The operation must satisfy explicitly stated closure and associativity conditions if an algebra is claimed.

Do not introduce a Clifford product merely because Clifford algebra is the target of comparison.

## D3 - Define metric/bilinear structure

A Clifford algebra is built from a quadratic/bilinear form.

The source supplies orthogonality language and orientation reversal, but does not by itself specify a metric signature.

Therefore:

- Euclidean signature must not be assumed;
- Lorentzian signature must not be assumed;
- the sign of the P4-related direction must not be silently identified with a metric sign.

Research question:

Can a bilinear form be derived from the processual structure, or must it be introduced as an external modelling choice?

If it is introduced externally, that provenance must remain explicit.

## D4 - Define anticommutator

For candidate generators e_mu, define

{e_mu,e_nu} = e_mu e_nu + e_nu e_mu

only after D2 defines the product.

Then determine whether the symmetric product closes on a scalar/bilinear form:

{e_mu,e_nu} = 2 g_mu_nu 1.

This equation is the Clifford target condition, not an assumption about Meta-Monism.

## D5 - Test Clifford relation

Only after D1-D4 are independently defined may we test whether

e_mu e_nu + e_nu e_mu = 2 g_mu_nu 1

holds.

Passing D5 would establish a mathematical correspondence of the constructed algebra with a Clifford algebra of the derived signature.

It would still not establish:

- physical identity with Dirac matrices;
- spin-1/2;
- the Dirac equation;
- quantum mechanics;
- physical validity of the ontodynamic model.

Those require separate research programs.

## Orientation reversal

The source gives +n -> -n.

Introduce a working operator R only as a research object:

R(n) = -n.

Do not assign an algebraic law to R in advance.

The next question is whether the processual structure constrains:

- R^2 = +1;
- R^2 = -1;
- R^2 = another operator;
- or no closed relation at all.

The answer must be derived from the formalized process, not selected to match spinor theory.

## Representation problem

If an algebra A is obtained, then seek a representation

rho : A -> Mat(n,F).

The dimension n is not assumed.

The correct sequence is:

processual data -> abstract algebra -> relations/signature -> representation problem -> minimal representation dimension.

The fact that standard Dirac gamma matrices are commonly represented by 4x4 matrices is an external mathematical fact and does not determine n here.

## Success criteria

D1 passes only if a carrier is explicitly defined without importing the target algebra.

D2 passes only if a composition law is independently defined.

D3 passes only if the bilinear/quadratic structure and its provenance are explicit.

D4 passes only if the anticommutator follows from the defined product.

D5 passes only if the Clifford relation is verified rather than stipulated.

A failure at any stage is preserved as a research result.

## Forbidden inferences

- Four processual stages imply four gamma matrices.
- Orthogonality implies the Clifford product.
- +n -> -n proves spin-1/2.
- A sign reversal is automatically a Clifford metric sign.
- A 4-stage process automatically has a 4x4 matrix representation.
- A constructed Clifford representation proves the physical model.
- Structural correspondence proves physical identity.


## Normative correction: orthogonality-constrained exhaustion

The D_ext + generic J_R formulation is now superseded as the primary working model for P3 -> P4.

The reason is source-structural: continuation is required to remain orthogonal. Therefore the relevant feasibility object is not the set of all outgoing transitions but the set of transitions satisfying the orthogonality constraint.

Define the working object:

D_perp^R(S) = { S' | Continue_R(S,S') and Orth_R(S,S') }.

Exhaustion is:

D_perp^R(S) = emptyset.

Frustration is:

NeedContinue(S) and D_perp^R(S) = emptyset.

For P3, the claim is specifically that the old regime has exhausted its admissible orthogonal continuation. This does not mean that orthogonality is globally exhausted.

The successor P4 must therefore be treated as an orthogonal resolution candidate:

P4 ∈ Sol_perp(P3,R_old).

The orientation change +n -> -n is attached to this source-grounded P3 -> P4 resolution. It is not introduced first as an independent algebraic operator.

The resulting construction order is:

processual structure
