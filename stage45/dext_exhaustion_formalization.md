# D_ext Formalization — Available Continuations and Exhaustion

## Research question

Can the source-level statement that further external orthogonal unfolding is exhausted after P3 be represented by a minimal mathematical object without assuming a metric, Clifford algebra, or fourth spatial dimension?

## 1. Minimal state

Let a process state be represented by:

S = (P, R, N, C)

where:

- P is the current processual position;
- R is the current continuation regime;
- N is the current orientation datum;
- C is the set of constraints governing admissible continuation.

This is a working formalization, not source notation.

## 2. External continuation set

For a state S define:

D_ext(S) = { d | d satisfies the current external-orthogonal continuation rule under C }

An element d is therefore not a coordinate and not automatically a vector. It is an admissible continuation possibility.

This is deliberately weaker than introducing a vector space.

## 3. Exhaustion

Define the exhaustion predicate:

E(S) := [ D_ext(S) = ∅ ]

This captures the source statement that no further continuation by the previous external orthogonal method is available.

No numerical dimension is required.

## 4. Continuation requirement

Define:

N(S) := [ continuation of the process is required ]

Then frustration is represented as:

Fr(S) := N(S) ∧ E(S)

This is a formalization of the source definition:

necessity of continuation + impossibility of completion by the previous method.

## 5. Ordinary continuation

If:

D_ext(S) ≠ ∅

then an ordinary continuation transition may be selected:

T_d : S → S'

for some d ∈ D_ext(S), subject to C.

The selection rule is intentionally left unspecified.

## 6. Exhaustion transition

If:

D_ext(S) = ∅

while N(S) remains true, an ordinary T_d transition is unavailable.

The process therefore requires a different transition class:

J : (S, Fr, R) → S'

with:

R' ≠ R

and, source-groundedly,

N' = -N

for the orientation datum when the Chapter 3 transition is instantiated.

The symbol J denotes a regime-changing transition, not yet a linear operator.

## 7. Why J is not a reflection

An ordinary reflection is normally defined on a fixed carrier and can be composed with itself. Here J changes the continuation regime because the old continuation set has become empty.

Therefore:

J² is undefined at this stage.

It is invalid to infer:

J² = I

or:

J² = -I

until a common carrier, composition law, and domain/codomain structure have been independently defined.

## 8. Boundary interpretation

The exhaustion transition can be viewed as a boundary of the current continuation regime:

∂R := { S | D_ext(S) = ∅ and N(S) = true }

This is a working definition.

The boundary is not a physical surface and does not imply a geometric boundary in ordinary space.

It is a boundary in the space of admissible process continuations.

## 9. Minimal transition system

The resulting process grammar is:

S --T_d--> S'       if d ∈ D_ext(S)

S --J--> S'         if D_ext(S)=∅ ∧ N(S)=true

with:

J changing the continuation regime.

For Chapter 3:

P3 --J--> P4

and:

+n → -n

The important distinction is:

P3 → P4 is not generated by an additional available external direction.

It is generated by the failure of the old continuation rule.

## 10. Optional rank formalization

Only if D_ext is later given vector-space structure may we define:

r_ext(S) = dim D_ext(S)

The working model

r_ext(P0)=3
r_ext(P1)=2
r_ext(P2)=1
r_ext(P3)=0

remains a proposal.

The formal theory does not depend on these numbers.

## 11. First algebraic consequence

There are now two qualitatively different composition classes:

1. continuation composition:
   T_d followed by T_e

2. regime-change composition:
   T_d followed by J, or J followed by a continuation in the new regime.

Thus the natural candidate structure is not initially a single algebra with one binary product.

It is a **regime-indexed transition system**:

(R, D_ext, T, J)

with transition composition defined where source and target regimes match.

A later algebra may be constructed from operators representing these transitions, but that is a separate research step.

## 12. Connection to Clifford research

This revision changes the Dirac/Clifford question.

The relevant generators need not be P1, P2, P3, P4.

A more faithful candidate set is:

G = {T_1, T_2, T_3, J}

where T_i represent processual continuation transitions and J represents exhaustion-induced regime change.

Even this is only a research hypothesis.

The next question is:

> Does a representation of the transition structure admit relations equivalent to a Clifford algebra?

No Clifford relation is assumed here.

## 13. Testable mathematical questions

Dext-1: Can D_ext be given a precise carrier without importing ungrounded geometry?

Dext-2: Can exhaustion be represented as loss of admissible transitions rather than loss of physical dimensions?

Dext-3: Can J be defined as a partial transition whose domain is exactly the frustration boundary?

Dext-4: Does J induce a nontrivial transformation of orientation data?

Dext-5: Can continuation transitions and J be represented as operators on one common carrier?

Dext-6: If so, what algebraic relations follow from the process rather than from analogy?

Dext-7: Does that algebra contain a Clifford sector?
