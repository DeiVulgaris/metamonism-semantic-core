# Stage 49 — Actualization Domain Scope

This stage fixes the scope of the foundational invariant.

Core distinction:

D = possibility space
Dom(P) = actualization domain
R = actualized result
trajectory = continuing sequence of actualized states

The invariant constrains actualization:

(I,I) notin Dom(P)

It does not mean that the entire possibility space D is globally prohibited from containing identity-like configurations.

Chapter 2 consequences are scoped to continuing actualization trajectories.

Orthogonal resolution and P4 are likewise trajectory-level structures.
