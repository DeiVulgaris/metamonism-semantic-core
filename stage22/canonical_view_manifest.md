# Stage 22 — Canonical Semantic Core View

## Purpose

Construct one canonical, machine-readable **view** over the already registered semantic core.

This is a derived representation. It does not become a new semantic authority.

## Authority order

1. Stage 11–13 source registries
2. Stage 10 cross-source bridge X1–X21
3. Stage 16 provenance
4. Stage 17 formalizations
5. Stage 22 canonical view

If the view conflicts with a registry, the registry wins and the view is invalid.

## Preservation requirements

The view MUST preserve:
- inventory scope;
- entity/claim/relation distinction;
- epistemic status;
- provenance;
- formalization references;
- unresolved/hypothesis/model boundaries;
- A/B/C operator separation;
- X1–X21 bridge status.

The view MUST NOT add:
- semantic identity;
- causal relations;
- mathematical equivalence;
- negative independence relations;
- new claims;
- new entities;
- new cross-source edges.

## Canonical means

"Canonical" here means **canonical aggregation of registered material**, not canonical truth of the underlying theory.
