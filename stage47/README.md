# Stage 47 — Orthogonality Necessity Derivation

This stage asks why orthogonality appears in the processual chain.

It establishes a negative result first:

**The ban on absolute identity alone does not determine orthogonality.**

It then tests conditional mathematical routes in which orthogonality can emerge from preservation of an invariant relation.

The central unresolved question is:

> Which property of the invariant relation makes orthogonal continuation necessary rather than merely possible?
