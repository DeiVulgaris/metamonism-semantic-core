# Stage 33 — Research Program Layer\n\n## Purpose\n\n`RESEARCH_PROGRAM` is the controlled workspace in which Meta-Monism can continue to think.\n\nThe canonical semantic core answers:\n> What is established in the corpus?\n\nThe research-program layer additionally preserves:\n> What are we trying to understand next, what prevents us from answering it, what can be tested, and what result would change the status?\n\n## Core principle\n\n**The system must preserve the conditions for continuation of reasoning.**\n\nAn unresolved hypothesis is therefore not a defective record. It is a valid research state when its provenance, assumptions, blockers, tests and next transition are explicit.\n\n## State machine\n\n`OPEN → FORMALIZING → TESTING → PARTIALLY_SUPPORTED / BLOCKED / REJECTED / SUPPORTED → INTEGRATED`\n\nThe lifecycle describes the state of the investigation, not truth.\n\nA program can branch into competing hypotheses. Failed tests are retained as research history and can generate new programs.\n\n## Required elements\n\nEvery program contains:\n1. research question;\n2. source-grounded claims;\n3. working entities;\n4. proposed relations;\n5. candidate formalizations;\n6. required definitions;\n7. tests and expected observations;\n8. falsifiers;\n9. derivations and hidden assumptions;\n10. counterexamples;\n11. open questions;\n12. forbidden inferences;\n13. an explicit next transition.\n\n## Canonical isolation\n\n`RESEARCH_PROGRAM` is a working layer.\n\nIt does **not** modify the canonical ontology merely because a hypothesis is coherent, repeated, elegant, computationally convenient, or apparently analogous to an established theory.\n\nPromotion requires the existing semantic validation and registration gates.\n\n## Why this matters\n\nA conventional semantic database tends to privilege completed statements. That creates a dangerous pressure: unresolved thought gets silently converted into definitions, and definitions then appear to be established theory.\n\nThis layer reverses that pressure.\n\nThe important object is not only the current answer. It is the **trajectory by which an answer may become possible**.\n\nTherefore the research state itself is machine-readable.\n\n## Current programs\n\n- `mm:rp.r1_r4_dirac` — R1-R4 recursive closure ↔ Clifford/Dirac structure.
